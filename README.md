# 📊 Dashboard Financeiro - Acompanhamento de Custos

## 🚀 Sobre o projeto

Este projeto consiste em um dashboard interativo desenvolvido com Streamlit para análise financeira e acompanhamento de custos.

O objetivo é fornecer uma visão estratégica para tomada de decisão, permitindo identificar tendências, gargalos e oportunidades de redução de custos.

---

## 📌 Funcionalidades

* Upload de planilhas Excel
* KPIs financeiros (custo total, média mensal, variação)
* Filtros dinâmicos (data, fornecedor, categoria, centro de custo)
* Visualizações interativas (Plotly)
* Análise de top fornecedores
* Distribuição de custos
* 🔮 Previsão de custos com Machine Learning (Prophet)

---

## 🧠 Tecnologias utilizadas

* Python
* Streamlit
* Pandas
* Plotly
* Prophet (Machine Learning)

---

## 📈 Insights gerados

* Identificação de aumento/redução de custos
* Tendência futura de gastos
* Principais categorias de impacto financeiro
